# Весь Python за один урок — видео

Генератор обучающего видео (1920×1080, 30 fps, ~13 минут, 24 главы): от `print`
до классов, генераторов и декораторов. Всё собирается кодом — сценарий, монтаж,
анимация, звук.

## Что в кадре

- заставка и финальный экран с анимацией;
- карточка-переход для каждой главы (номер + название) со звуком «вжух»;
- редактор кода с подсветкой синтаксиса: код **печатается синхронно с речью**,
  с курсором, номерами строк, подсветкой текущего блока и звуком клавиш;
- терминал с **настоящим выводом** — каждый пример реально выполняется при сборке;
- субтитры, прогресс-бар с отметками глав, плавающий градиентный фон;
- фоновая музыка (эмбиент), приглушается под голос.

## Сборка

Нужны Python 3.12+, `ffmpeg`, `pip install pillow numpy`.

```bash
cd video
pip install edge-tts
python3 voice.py        # натуральная озвучка нейросетевым голосом (нужен интернет)
python3 render.py       # сборка -> build/python_za_odin_urok.mp4
```

Без `voice.py` видео тоже собирается — с субтитрами и музыкой, а длительность
фраз оценивается по тексту. После озвучки тайминг подстраивается под реальную длину
каждой фразы, так что код печатается ровно под голос.

Рядом с видео появляются `build/subtitles.srt` и `build/chapters.txt` (таймкоды
глав для описания на YouTube).

### Полезное

- `python3 voice.py --voice ru-RU-SvetlanaNeural` — женский голос;
  `--rate +8%` — чуть быстрее.
- Свой голос: положите записи в `video/voice/SS_KK.wav` (SS — номер сцены,
  KK — номер фразы, с нуля) — они подхватятся автоматически.
- `python3 render.py --preview 9 20` — кадр сцены 9 на 20-й секунде.
- `python3 render.py --scenes 0-2` — собрать только часть сцен.
- Текст, код и порядок глав — в `video/script.py`. Запись `{print|принт}`
  значит: в субтитрах «print», а диктор говорит «принт».
